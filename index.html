API v1

نگهبان را به محصول خودت وصل کن.

  • بررسی تکی و دسته‌ای تا ۳۲ متن
  • سانسور خودکار و حکم جمله‌به‌جمله
  • سازگار با Moderation API اوپن‌ای‌آی
  • لینک زنده همیشه در api/links.json
دیدن همه‌ی مسیرها
curl -X POST https://YOUR-LINK.trycloudflare.com/api/v1/check \
  -H "Content-Type: application/json" \
  -d '{"text": "to khar hasti"}'

  "decision": "TOXIC",
  "confidence": 0.91,
